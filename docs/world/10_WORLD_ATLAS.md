# HOLLOW CORE — АТЛАС МИРА И КАРТОГРАФИЯ (WORLD ATLAS)
*Трехмерная топография, координатная сетка, вертикальные разрезы и транспортные артерии*
*Версия: 1.0 // Спецификация вселенной Hollow Core (Godot 4.7+)*

---

## 1. СИСТЕМА КООРДИНАТ И МАСШТАБЫ

Координатная сетка Hollow Core использует метрическую систему (1 воксель = 1 кубический метр):
- **Ось X**: Запад (-X) <──> Восток (+X). Диапазон: `-120 .. +120` метров.
- **Ось Y**: Глубина/Высота. `Y = +55` (подошва ледника) <──> `Y = -60` (мантийный бедрок).
- **Ось Z**: Север (-Z) <──> Юг (+Z). Диапазон: `-120 .. +120` метров.

## 4. ТРАНСПОРТНЫЕ АРТЕРИИ И СВЯЗУЮЩИЕ ПУТИ

1. **Главный Акведук Каскада**: Водный желоб, позволяющий на плоту или вплавь спуститься с горизонта `Y = 30` до горизонта `Y = 15`.
2. **Шахтная Узкоколейка Синдиката**: Однопутная ветка протяженностью 300 метров с уклоном 12 градусов. Игрок может восстановить дрезину с ручным приводом для быстрого перемещения между Базальтовым Хабом и Келлер-Вайсом.
3. **Вертикальный Разлом «Труба Келлера»**: Расщелина глубиной 70 метров, оборудованная остатками деревянных лестничных маршей и тросов для дюльфера.
