# HOLLOW CORE — КАТАЛОГ СЕКРЕТОВ И ПАСХАЛОК (EASTER EGGS)
*Полный реестр 30 скрытых локаций, аномалий, артефактов и технических механик*
*Версия: 1.0 // Спецификация вселенной Hollow Core (Godot 4.7+)*

---

## 1. ПРИНЦИПЫ ИНТЕГРАЦИИ СЕКРЕТОВ В ИГРОВОЙ ДВИЖОК

Каждый секрет в Hollow Core — это не просто декорация, а полноценный интерактивный узел:
- **Техническая сущность**: SecretNode (Area3D с коллизией слоя 4 Interactable и скриптом interactive_secret.gd).
- **Флаг сохранения**: При обнаружении пишется в StoryState.unlocked_secrets[secret_id] = true.
- **Звуковая обратная связь**: Воспроизведение пространственного 3D-звука обнаружения тайны (secret_resonance_chime.wav).
